# AgentTrace 실측 성능 수치

아래 수치는 모두 아래 환경에서 `benchmarks/measure.py`를 실제로 실행해 얻은
측정값입니다. 추정치가 아니며, 같은 스크립트로 재현할 수 있습니다.

- 측정일: 2026-10-05
- CPU: 11th Gen Intel Core i7-11700F @ 2.50GHz
- RAM: 32GB
- OS: Windows 11 Pro
- Python: 3.10.0
- 측정 방법: 각 항목 200회 워밍업 후 `time.perf_counter_ns`로 반복 측정,
  단일 머신 벽시계 기준. 표본 수(n)는 항목별 표기.

---

## 표 8용 한 줄 (요청하신 형식)

| 항목 | 값 |
|---|---|
| **판정 지연** | **평균 0.08 ms (약 85 µs), 실측 (n=5000)** |

> "판정 지연"은 관문(`Guard.evaluate`)이 명령 한 건을 허용/확인/차단으로 판정하는
> 순수 처리 시간입니다. 정책 규칙 전체를 스캔하는 허용 판정(최악 경우) 기준입니다.
> 판정 결과를 변조 방지 기록(해시 체인, SQLite)까지 남기는 **전체 경로**는 평균 3.76 ms입니다.

---

## 1. 관문 판정 지연 (`Guard.evaluate`, 순수 판정, 기록 제외)

| 판정 종류 | n | 평균 | 중앙값 | p95 | p99 | 최대 |
|---|--:|--:|--:|--:|--:|--:|
| 허용 (전체 규칙 스캔) | 5000 | 84.56 µs | 77.30 µs | 124.00 µs | 164.30 µs | 380.70 µs |
| 차단 (인코딩 PowerShell) | 5000 | 79.66 µs | 72.30 µs | 115.20 µs | 152.80 µs | 272.00 µs |
| 차단 (원격 다운로드) | 5000 | 81.07 µs | 72.50 µs | 118.90 µs | 157.30 µs | 337.20 µs |
| 확인 (오염 세션 격상) | 5000 | 83.83 µs | 76.60 µs | 123.10 µs | 180.10 µs | 310.70 µs |

판정 지연은 판정 종류와 무관하게 평균 약 80~85 µs(0.08 ms)입니다. 즉 초당 약 1만 건
이상을 판정할 수 있어, 에이전트의 명령 실행을 사람이 체감할 지연 없이 가로막습니다.

## 2. 관문 전체 경로 (판정 + 해시 체인 기록, SQLite 파일)

| 항목 | n | 평균 | 중앙값 | p95 | p99 | 최대 |
|---|--:|--:|--:|--:|--:|--:|
| `guard_action` (판정 + 기록) | 2000 | 3.76 ms | 3.56 ms | 4.62 ms | 5.85 ms | 30.10 ms |

판정 자체(0.08 ms)보다 느린 것은 디스크에 변조 방지 기록(append-only 해시 체인)을
남기기 때문입니다. 그래도 평균 3.76 ms로, 실행 전 관문에 걸어도 무리가 없습니다.

## 3. 부가 실측

| 항목 | n | 평균 | 중앙값 | p95 | 최대 |
|---|--:|--:|--:|--:|--:|
| 지문 생성 `fingerprint()` | 5000 | 9.36 µs | 6.90 µs | 14.70 µs | 59.30 µs |
| 역추적 `trace.analyze()` (3노드 체인) | 5000 | 20.84 µs | 18.00 µs | 33.60 µs | 117.20 µs |
| 해시 체인 검증 `verify_chain()` (500 레코드) | 500 | 2.14 ms | 1.93 ms | 3.02 ms | 3.56 ms |

## 재현 방법

```bash
python benchmarks/measure.py
```

출력의 각 행이 위 표의 한 줄에 대응합니다.

## 한계 및 주의

- 단일 머신 1회 측정 결과입니다(벽시계 기준). 다른 CPU에서는 값이 달라집니다.
- 판정 지연은 현재 정책 규칙 수(6개)와 차단 목록(없음) 기준입니다. 규칙을 크게 늘리면
  허용 판정(전체 스캔)이 비례해 느려질 수 있습니다.
- 전체 경로 시간은 디스크 속도(SSD/HDD)에 영향을 받습니다.
- Sysmon 수집 처리량은 Sysmon 설치 환경이 필요해 이 표에 넣지 않았습니다. 설치 환경에서
  별도 측정이 필요합니다.
