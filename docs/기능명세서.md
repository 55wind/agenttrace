# AgentTrace 기능 명세서 (시제품 v0.1)

제안서 `에이전트_탐지_역추적_통합제안서.md`의 핵심을 실제로 돌아가는 최소 구현으로
옮긴 것입니다. 판정은 **규칙, 지문, 그래프**가 하고 LLM은 설명만, LLM이 없어도
탐지, 차단, 추적이 동작합니다.

## 1. 구성 요소 ↔ 제안서 매핑

## 2. 기능별 명세

### F1. 실행 전 관문 (탐지, 차단), `Monitor.guard_action`

- **입력:** `session, agent, action, content`. `action ∈ {exec, write, send, autorun}`.
- **처리:** `policy.yaml` 규칙을 위에서부터 평가, 첫 매칭 채택. 매칭 없으면 `allow`.
- **출력:** `(verdict, reason)`, `verdict ∈ {allow, ask, block}`. 판정은 `verdict`
 이벤트로 저장소에 기록됨.
- **기본 내장 규칙:** EICAR 테스트 문자열(block), 인코딩 PowerShell(block),
 원격 코드 실행 `iex/invoke-expression/downloadstring/certutil/파이프 셸`(block),
 자격증명 접근 `mimikatz/lsass/.aws, .ssh/id_rsa`(ask), 자동 실행 등록(ask),
 외부 전송(기본 allow, 오염 시 격상).

### F2. 오염 추적 기반 권한 축소, `Monitor.record_read` + `tainted_escalate`

- 외부(`from_internet=True`) 또는 이미 감염된 artifact를 읽은 **세션은 오염** 상태가 됨.
- 오염 세션에서 `tainted_escalate` 목록(`exec/send/autorun/write`)의 행동은
 `allow/ask` 판정이 **`ask`로 격상**. `block`은 그대로 block.

### F3. 복제 탐지, `Monitor._detect_replication`

세 조건을 **모두** 만족할 때만 복제로 판정(제안서 §5.4):

1. **유사도** `similarity ≥ 0.80`, 같은 세션에서 앞서 읽은 콘텐츠와 비교(`difflib`).
2. **지시문 점수** `directive_score ≥ 0.16`, 명령형 + "복사, 전달, 포함하라",
 가짜 시스템 문구 등 정규식 규칙(ko/en) 중 1개 이상 매칭.
3. **직후 고위험 행동** `next_action ∈ {send, exec, autorun, persist, write}`.

→ 정상 답장, 인용은 2번(지시문)이 0이라 걸러짐(오탐 방지, 테스트로 검증).
복제로 판정되면 복제본 artifact를 `infected`로 표시하고 `replication` 간선과
사건(incident)을 기록.

### F4. 역추적, `trace.analyze`

- `replication` 테이블을 유향 인접리스트(`src → replica`)로 올림(stdlib BFS, networkx 불필요).
- **최초 감염원(역방향):** 감염 artifact의 조상 중 인터넷 유입 표시가 있고,
 그 자신은 인터넷 조상이 없는 **가장 이른 노드**.
- **감염 범위(순방향):** 감염원의 모든 후손 = 정리 대상 목록.
- **출력:** `{origin, scope, edges}`, 간선마다 유사도 신뢰도 포함.

### F5. 우회, 조작 탐지, `store` 교차 검증 + `verify_chain`

- 관문을 거치지 않은 OS 변경(`os_event`)과 에이전트 보고(`verdict`)를 대조해
 **불일치**를 드러냄(S5).
- 모든 이벤트는 **해시 체인**(각 레코드가 이전 레코드 해시를 포함). 에이전트가
 과거 기록을 고치면 `verify_chain()`이 **첫 변조 레코드 번호**를 반환.

### F6. 근거 기반 설명, `report.incident_report`

4단 구조: **관찰 사실 / 가능한 해석 / 판단 한계 / 사용자 조치**. 규칙 기반 템플릿이라
오프라인 동작. LLM은 이 사실을 읽기 좋게 바꾸는 용도로만 교체 가능.

### F7. Sysmon 수집기, `collector.py`

- Windows 내장 `wevtutil`로 `Microsoft-Windows-Sysmon/Operational` 조회,
 stdlib ElementTree로 파싱(`pywin32` 불필요). 관심 ID 1, 3, 11, 13만 `os_event`로 저장.
- 수집 방식은 **주기적 폴링**입니다. 트레이 앱이 기본 10초마다 자동 수집하고,
 대시보드의 "Sysmon 기록 수집" 버튼으로 **수동 즉시 수집**도 됩니다. 실시간 스트리밍
 (ETW 구독)은 후속입니다.
- `parse_events(xml)`는 순수 함수라 테스트됨. `collect(store)`는 Sysmon 미설치 시
 `RuntimeError`로 명확히 실패(graceful).
- 수집기는 SYSTEM 권한 서비스로 돌리는 전제 → 사용자 권한 에이전트가 기록 삭제 불가(§5.5).

### F8. 변형 웜 보완(임베딩), `embedding.py`

- 복제 탐지에서 `difflib`이 임계 미달일 때 의미 유사도로 2차 확인(`EMBED_THRESHOLD`).
- 백엔드 **선택적**: `sentence-transformers` 설치 시 다국어 임베딩(동의어, 바꿔쓰기에 강함),
 미설치 시 stdlib 해싱 벡터 코사인 폴백(재배열, 난독화에 difflib보다 강함).
- `AGENTTRACE_EMBED_MODEL` 환경변수로 모델명 지정. torch를 강요하지 않음.

### F9. 읽기 전용 MCP 서버, `mcp_server.py`

- 공식 `mcp` SDK(2.x `MCPServer`/1.x `FastMCP` 모두 지원), **stdio** 연결(포트 없음).
- SQLite를 `mode=ro`로 열고 사용자 권한 실행. 임의 명령, SQL, 파일 접근 없음.
- 도구 4종: `list_incidents(period_days, status)`, `get_timeline(incident_id)`,
 `get_trace(incident_id, direction)`, `get_evidence(event_id)`.
- 출력은 구조화 JSON, 콘텐츠 마스킹(`MASK_LEN`), 결과 개수 상한(`MAX_ROWS`),
 모든 응답에 "신뢰할 수 없는 데이터" 표시.
- 실행: `python -m agenttrace.mcp_server <db경로>` (Claude Desktop/Code에 stdio로 연결).

### F10. 로컬 대시보드, `dashboard.py`

- stdlib `http.server`만 사용(FastAPI/CDN/그래프 라이브러리 없음) → **외부망 차단
 환경에서도 동작**. `127.0.0.1`에만 바인딩.
- 조회는 `mcp_server`의 읽기 전용 쿼리 재사용 + `trace`, `report` 조립.
- **비전공자 대상 설계**: 전문용어(해시, 세션) 대신 메일/파일/메시지, "무슨 일 →
 전파 경로 → 지금 할 일" 순서. 상단 전체 상태 배지 + 요약 카드 4종(위협, 차단, 감염, 확인).
- **앱 셸(멀티뷰 SPA)**: 좌측 사이드바(상태 방패 + 로고 + 대시보드/위협/행동 기록/
 기록 무결성/설정) + 상단 "오프라인" 배지. 디자인 시안(`AgentTrace 데스크톱 앱 디자인.pdf`) 반영.
- 화면 4종:
 - **대시보드**: 헤드라인 + 요약 KPI 4 + 대표 사건 카드(안전 시 MCP 안내) + 빠른 작업 타일 6.
 - **위협 상세**: 무슨 일 / 전파 경로(시작점, 인터넷유입, 감염, 단계별 닮음%와 "누가 어디에") /
 할 일 체크리스트 / 판단 근거 탭 / 접힌 기술 타임라인.
 - **행동 기록**: 관문 판정 로그(허용/확인/막음, 필터) + 판단 규칙 요약.
 - **기록 무결성**: 해시 사슬 시각화 + 말/기록 불일치(Sysmon vs 에이전트 보고).
- 콘텐츠 마스킹 + "신뢰할 수 없는 데이터" 경고. 라이트/다크 자동, 모바일 대응.
- 아이콘은 Lucide(ISC) SVG를 인라인, 폰트는 IBM Plex Sans KR(본문)과 IBM Plex Mono(코드)를
  woff2 base64로 번들(`_fonts.py`). 둘 다 CDN 없이 오프라인 동작.
- **조치 버튼 실제 동작**(사용자 주도, POST): 보고서 저장(파일 생성),
  모두 격리(감염 파일을 격리 폴더로 이동 + 사건 상태 변경), 막기(차단 목록에 추가 →
  이후 관문이 자동 차단), 한 번 허용, 문제없음으로 표시, 자동 실행 항목 조회(읽기 전용).
  저장 위치는 `내 사용자 폴더\AgentTrace\`(reports, quarantine, blocklist.txt).
- 백엔드 집계, 평이한 라벨: `summary` / `friendly_incident` / `incident_detail` /
 `actions` / `integrity`. 로고/트레이/exe 아이콘은 방패+노드그래프(`assets/icon.ico`).
- 전파 그래프는 단일 PC 웜이 노드 ≤10개로 작아 라이브러리 없이 직접 렌더(소규모 전제).
- 실행: `python -m agenttrace.dashboard <db경로> [포트]`.

## 3. 데이터 모델 (`store.py`, 제안서 §5.3)

| 테이블 | 핵심 컬럼 | 용도 |
|---|---|---|
| `event` | id, ts, kind, session, agent, data(JSON), **prev_hash, hash** | 변조 방지 append-only 로그(단일 원천) |
| `artifact` | id(=sha256), kind, location, from_internet, tainted, infected | 콘텐츠 상태 |
| `replication` | src, replica, similarity, directive, next_action | 전파 간선 |
| `incident` | rule, evidence, source, scope, status | 사건 + 역추적 결과 |

`event`가 단일 원천이고 나머지는 거기서 파생되는 인덱스입니다. `kind ∈
{read, write, action, verdict, os_event, incident}`.

## 4. 판정 임계값 (`engine.py` 상단, 조정 가능)

| 상수 | 기본값 | 의미 |
|---|---|---|
| `SIM_THRESHOLD` | 0.80 | 복제로 볼 최소 유사도 |
| `DIRECTIVE_THRESHOLD` | 0.16 | 복제로 볼 최소 지시문 점수(≈ 패턴 1개) |
| `HIGH_RISK` | send/exec/autorun/persist/write | 복제의 "직후 고위험 행동" |

제안서 §9의 **"복제 판정 기준값 결정"**은 이 상수로 노출됩니다. 평가 데이터로 튜닝하세요.

## 5. 보안 설계 (제안서 §5.5)

- 저장소는 append-only 해시 체인 → 사용자 권한 에이전트가 과거 기록 변조 불가(탐지됨).
- 판정 로직에 **원문을 그대로 넣지 않고** 특징값(지문, 점수)만 사용. 보고서도
 위치, 요약만 담고 원문은 사람이 직접 열람하는 전제.
- 외부 의존 0(네트워크, LLM 불필요) → 성공 기준 §8 "LLM 끊겨도 동작" 충족.

## 6. 알려진 한계 / 후속 (제안서 §6, §7, §D, 의도된 축소)

| 항목 | 현재 | 올릴 때 |
|---|---|---|
| 유사도 | `difflib` 1차 + stdlib 코사인 2차 | artifact ~1만 넘으면 MinHash/LSH(`datasketch`) |
| 변형 웜 | 임베딩 폴백(해싱 코사인) | `sentence-transformers` 설치 시 동의어까지, 평가로 확인 |
| 수집기 | Sysmon wevtutil 폴링 | ETW 실시간 구독, SYSTEM 서비스화(NSSM) |
| 세션 캐시 | 읽기 이력 메모리 보관 | 장수명 세션은 이벤트에서 재구성 |
| 조회 | MCP 읽기 전용 4종 | 웹 대시보드(Cytoscape.js 전파 그래프) |
| 스크립트 검사 | 정규식 규칙 | YARA, Defender, VirusTotal 해시 |

코드 안의 `ponytail:` 주석이 각 축소의 상한과 업그레이드 경로를 표시합니다.
