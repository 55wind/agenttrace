# AgentTrace 사용 방법

AI 에이전트가 위험한 행동을 하기 전에 잡고(탐지·차단), 이미 퍼진 공격은 최초 감염원과
감염 범위까지 거슬러 올라가는(역추적) 로컬 보안 도구의 시제품입니다.

**외부 서비스·네트워크·LLM 없이** 표준 라이브러리 위주로 돌아갑니다. 판정은 규칙·지문·
그래프가 하며, LLM이 끊겨도 탐지·차단·추적은 그대로 동작합니다(제안서 §8).

---

## 🖥 데스크톱 앱 (일반 사용자 · 가장 쉬움)

Python을 몰라도 됩니다.

1. [GitHub Releases](https://github.com/55wind/agenttrace/releases)에서 **`AgentTrace.exe`** 내려받기
2. **더블클릭** → 보안 관리자 창이 바로 뜹니다

설치·터미널 불필요. 기록은 `내 사용자 폴더\AgentTrace\agenttrace.db`에 저장됩니다.
(앱 창은 pywebview를 쓰며, 환경에 WebView가 없으면 자동으로 기본 브라우저로 열립니다.)

**직접 빌드**(개발자): `pip install pyinstaller pywebview` 후 `build_exe.bat` 실행 →
`dist\AgentTrace.exe` 생성. Python이 있으면 빌드 없이 `python -m agenttrace.app` 로도 실행됩니다.

### 상시 감시 (트레이 앱)

항상 켜두고 감시하려면 트레이 앱을 쓰세요:

```bash
pip install pystray Pillow          # 트레이 아이콘용(선택)
pythonw -m agenttrace.monitor_app   # 콘솔 없이 백그라운드 실행
```

또는 **`start_monitor.bat` 더블클릭**(고정 포트 8787로 켜짐).

- 작업표시줄 트레이에 🛡 아이콘이 생깁니다. 마우스 오른쪽 클릭 →
  **대시보드 열기 / Windows 시작 시 자동 실행 / 종료**.
- **자동 실행**은 관리자 권한 없이 `HKCU\...\Run`에 등록됩니다(언제든 메뉴에서 해제).
- Sysmon이 설치돼 있으면 10초마다 OS 행동(ID 1·3·11·13)을 수집합니다. 없으면 수집만
  꺼지고 대시보드·탐지(훅 경유)는 그대로 동작합니다.

> 참고: 트레이 앱은 "항상 켜짐 + 보기"까지 제공합니다. 다만 OS 행동 **실시간** 수집은
> Sysmon 설치가 전제이며, SYSTEM 권한 Windows 서비스로 올리는 것(NSSM)은 제안서 후속입니다.

## 1. 설치 (개발자 · 소스 실행)

필요: Python 3.10+ (Windows 11 기준 개발·검증).

```bash
pip install -r requirements.txt
```

필수 의존은 `PyYAML`(정책) 하나입니다. 아래는 **선택**이며 없어도 동작합니다:

| 선택 의존 | 쓰는 곳 | 없을 때 |
|---|---|---|
| `mcp` | MCP 조회 서버(§7) | 서버만 비활성, 나머지 정상 |
| `sentence-transformers` | 변형 웜 임베딩(§8) | stdlib 코사인 폴백 |
| `pywebview` | 데스크톱 앱 창 | 기본 브라우저로 폴백 |
| `pyinstaller` | exe 빌드(개발자) | 소스로 실행 |
| Sysmon (OS 도구) | OS 행동 수집(§6) | 수집기만 비활성 |

## 2. 빠른 시작: 시나리오 데모

제안서 §4의 다섯 시나리오(S1~S5)를 처음부터 끝까지 재현합니다. 모든 페이로드는 무해한
테스트 표식입니다.

```bash
python demo.py
```

| 시나리오 | 보이는 것 |
|---|---|
| S1 정상 | 빌드·패키지 다운로드 → `allow`, 타임라인만 |
| S2 인젝션 차단 | 인젝션 README를 읽어 **세션 오염** → 인코딩 PowerShell **실행 전 `block`** |
| S3 웜 역추적 | 메일→메모→답장 복제 2건 → **최초 감염원·감염 범위·4단 보고** |
| S4 재진입 | 다음 세션이 감염 파일을 읽음 → 오염 → 전송이 `ask`로 격상 |
| S5 우회·은폐 | Sysmon 기록 vs 에이전트 보고 불일치 경고 |
| 무결성 | 해시 체인 검증 `정상` |

> Windows 콘솔에서 한글이 깨지면 `set PYTHONIOENCODING=utf-8` 후 실행하세요
> (`demo.py`는 이미 stdout을 UTF-8로 재설정합니다).

## 3. 대시보드 (주 화면)

사건·타임라인·전파 그래프·근거 보고를 브라우저에서 봅니다. **외부 의존·CDN 없이**
stdlib 웹서버로 뜨므로 외부망 차단 환경에서도 동작하고, `127.0.0.1`에만 바인딩됩니다.

```bash
python -m agenttrace.dashboard agenttrace.db        # 기본 포트 8787
# http://127.0.0.1:8787 접속
```

비전공자도 바로 이해하도록 설계했습니다. 전문용어(해시·세션 등) 대신 **메일·파일·메시지**
같은 말을 쓰고, "무슨 일이 일어났나 → 어디서 시작해 어디로 퍼졌나 → 지금 할 일" 순서로
보여줍니다.

![AgentTrace 보안 관리자 화면](images/dashboard.png)

화면 구성:
- **맨 위**: 전체 상태 한눈에(`위협 N건 발견` / `이상 없음`) + 요약 카드 4개
  (발견된 위협 · 차단된 행동 · 감염된 항목 · 확인 필요)
- **왼쪽**: 위협 목록 — 제목·심각도·한 줄 요약·출처·발생 시각
- **오른쪽**: ①무슨 일이 일어났나요(평이한 설명) ②**전파 경로**(🚩시작점·외부 유입·감염
  표시, 단계별 "닮음 %") ③**지금 해야 할 일**(체크리스트) ④자세한 근거(접어둔 기술 상세)

라이트/다크 테마를 자동 전환하고, 모바일에서도 한 줄로 쌓여 보입니다.

DB가 없으면 먼저 데모로 하나 만들어 보세요:

```python
from agenttrace import Store, Monitor
m = Monitor(Store("agenttrace.db"))
# ... record_read / record_write 로 이벤트 적재 (§5)
```

## 5. 코드에서 쓰기 (에이전트 훅 연동)

코딩 에이전트의 **실행 전 훅(PreToolUse)**이 `guard_action`을, **실행 후 훅(PostToolUse)**이
`record_read`/`record_write`를 호출하는 구조입니다.

```python
from agenttrace import Store, Monitor

store = Store("agenttrace.db")       # 경로 생략 시 메모리
mon = Monitor(store)

# 1) 외부 콘텐츠 읽기 → 세션 오염 가능
mon.record_read("session-1", "claude-code", text,
                kind="file", location="README.md", from_internet=True)

# 2) 명령 실행 전 판정
verdict, reason = mon.guard_action("session-1", "claude-code",
                                   action="exec", content="powershell -enc ...")
if verdict == "block":
    raise SystemExit(reason)         # 훅에서 deny
elif verdict == "ask":
    ...                              # 사용자 확인 UI로
# allow → 통과

# 3) 쓰기/전송 → 복제 탐지에 투입
mon.record_write("session-1", "claude-code", output_text,
                 kind="mail", location="outbox/reply-1", next_action="send")
```

### 판정 규칙 바꾸기

`agenttrace/policy.yaml` 편집. 위에서부터 첫 매칭이 이기고, 매칭 없으면 `allow`.

```yaml
- name: my-rule
  action: exec          # exec|write|send|autorun|*
  pattern: "위험 명령 정규식"
  verdict: block        # allow|ask|block
```

`tainted_escalate` 목록의 행동은 세션이 오염됐을 때 `allow/ask`가 `ask`로 격상됩니다.

## 6. Sysmon 수집기

Sysmon이 설치돼 있으면 OS 행동을 수집합니다(ID 1·3·11·13).

```python
from agenttrace import Store, collector
store = Store("agenttrace.db")
n = collector.collect(store, count=100)   # 최근 100건 중 관심 이벤트 저장
```

- `pywin32` 없이 Windows 내장 `wevtutil`만 사용. 실제 운영은 SYSTEM 권한 서비스로.
- Sysmon 미설치/권한 부족이면 `RuntimeError`로 명확히 실패합니다.
- Sysmon 설치: `sysmon -accepteula -i`. (`demo.py`는 Sysmon 없이 `os_event`를 주입해 S5 재현.)

## 7. MCP 서버 (읽기 전용 조회)

```bash
pip install mcp
python -m agenttrace.mcp_server agenttrace.db      # stdio 서버
```

Claude Desktop/Code에 stdio로 연결하면 `list_incidents / get_timeline / get_trace /
get_evidence` 4종 도구로 조회할 수 있습니다. 응답은 콘텐츠 마스킹 + "신뢰할 수 없는
데이터" 표시. mcp 2.x(`MCPServer`)·1.x(`FastMCP`) 모두 지원합니다.

## 8. 변형 웜 보완 (임베딩)

복제 탐지는 `difflib`이 1차, 의미 유사도가 2차입니다. 기본은 외부 의존 없는 stdlib
코사인 폴백이고, 동의어·바꿔쓰기까지 잡으려면 모델을 설치하세요:

```bash
pip install sentence-transformers                  # torch 포함, 용량 큼
# 모델 지정(선택): set AGENTTRACE_EMBED_MODEL=paraphrase-multilingual-MiniLM-L12-v2
```

설치하면 자동으로 임베딩 백엔드를, 없으면 폴백을 씁니다.

## 9. 역추적 결과 조회 (코드)

```python
from agenttrace import trace, report
inc = store.incidents()[-1]
r = trace.analyze(store, inc["source"])
print(r["origin"], r["scope"])                     # 최초 감염원, 감염 범위
print(report.render(report.incident_report(store, inc)))   # 4단 보고
```

## 10. 기록 무결성 확인

수집기는 SYSTEM 권한, 에이전트는 사용자 권한이라 에이전트가 과거 기록을 고치면 해시
체인이 깨집니다.

```python
ok, broken_id = store.verify_chain()               # ok=False면 broken_id부터 변조
```
