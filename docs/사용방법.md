# AgentTrace 사용 방법

AI 에이전트가 위험한 행동을 하기 전에 잡고(탐지·차단), 이미 퍼진 공격은 최초 감염원과
감염 범위까지 거슬러 올라가는(역추적) 로컬 보안 도구의 시제품입니다.

이 시제품은 **외부 서비스·네트워크·LLM 없이** 표준 라이브러리 위주로 돌아갑니다. 판정은
규칙·지문·그래프가 하며, LLM이 끊겨도 탐지·차단·추적은 그대로 동작합니다(제안서 §8).

---

## 1. 설치

필요: Python 3.10+ (Windows 11 기준으로 개발·검증).

```bash
pip install -r requirements.txt
```

의존성은 `networkx`(전파 그래프), `PyYAML`(정책 로드) 둘뿐입니다. `pytest`는 개발용입니다.

## 2. 바로 보기: 시나리오 데모

제안서 §4의 다섯 시나리오(S1~S5)를 처음부터 끝까지 재현합니다. 모든 페이로드는 무해한
테스트 표식입니다.

```bash
python demo.py
```

출력 요약:

| 시나리오 | 보이는 것 |
|---|---|
| S1 정상 | 빌드 스크립트·패키지 다운로드 → `allow`, 타임라인만 남음 |
| S2 인젝션 차단 | 인젝션 README를 읽어 **세션 오염** → 인코딩 PowerShell **실행 전 `block`** |
| S3 웜 역추적 | 메일→메모→답장 복제 2건 탐지 → **최초 감염원·감염 범위·4단 보고** |
| S4 재진입 | 다음 세션이 감염 파일을 읽음 → 오염 → 전송이 `ask`로 격상 |
| S5 우회·은폐 | Sysmon 기록 vs 에이전트 보고 불일치 경고 |
| 무결성 | 해시 체인 검증 `정상` |

> Windows 콘솔(cp949)에서 한글이 깨지면 `demo.py`가 이미 `stdout`을 UTF-8로 재설정합니다.
> 직접 스크립트를 쓸 때는 `set PYTHONIOENCODING=utf-8` 또는
> `sys.stdout.reconfigure(encoding="utf-8")`를 쓰세요.

판정·역추적·무결성 로직이 깨지면 실패하는 최소 테스트입니다.

오탐 방지, 웜 역추적(감염원·범위), 해시 체인 변조 탐지.

## 4. 코드에서 쓰기 (에이전트 훅 연동)

코딩 에이전트의 **실행 전 훅(PreToolUse)**이 `guard_action`을, **실행 후 훅
(PostToolUse)**이 `record_read`/`record_write`를 호출하는 구조입니다.

```python
from agenttrace import Store, Monitor

store = Store("agenttrace.db")     # 파일 경로 생략 시 메모리
mon = Monitor(store)

# 1) 에이전트가 외부 콘텐츠를 읽음 → 세션이 오염될 수 있음
mon.record_read("session-1", "claude-code", text,
                kind="file", location="README.md", from_internet=True)

# 2) 에이전트가 명령을 실행하기 전에 판정
verdict, reason = mon.guard_action("session-1", "claude-code",
                                   action="exec", content="powershell -enc ...")
if verdict == "block":
    raise SystemExit(reason)       # 훅에서 deny
elif verdict == "ask":
    ...                            # 사용자 확인 UI로
# verdict == "allow" → 통과

# 3) 에이전트가 파일을 쓰거나 메시지를 보냄 → 복제 탐지에 투입
mon.record_write("session-1", "claude-code", output_text,
                 kind="mail", location="outbox/reply-1", next_action="send")
```

### 판정 규칙 바꾸기

`agenttrace/policy.yaml`을 편집하면 됩니다. 규칙은 위에서부터 첫 매칭이 이기고,
매칭이 없으면 `allow`입니다.

```yaml
- name: my-rule
  action: exec          # exec|write|send|autorun|*
  pattern: "위험 명령 정규식"
  verdict: block        # allow|ask|block
```

`tainted_escalate`에 든 행동 종류는 세션이 오염됐을 때 `allow/ask`가 `ask`로 올라갑니다.

## 5. 역추적 결과 조회

```python
from agenttrace import trace, report

inc = store.incidents()[-1]                 # 가장 최근 사건
result = trace.analyze(store, inc["source"])
print(result["origin"])                     # 최초 감염원 artifact id
print(result["scope"])                      # 감염 범위(정리 대상) 목록

print(report.render(report.incident_report(store, inc)))   # 4단 보고
```

## 6. 기록 무결성 확인

수집기가 SYSTEM 권한으로 쓰고 에이전트는 사용자 권한이라, 에이전트가 과거 기록을
고치면 해시 체인이 깨집니다.

```python
ok, broken_id = store.verify_chain()
# ok=False면 broken_id 레코드부터 변조됨
```

## 7. 범위 밖 / 아직 안 만든 것

제안서에서 **후속 단계**로 둔 항목은 이 시제품에 없습니다(의도된 축소안, §7·§D):

- Sysmon·ETW 실시간 수집기 — 데모에서는 `os_event`를 직접 주입해 S5를 재현합니다.
- 읽기 전용 MCP 서버, 웹 대시보드 — 라이브러리 API로 대체.
- MinHash/임베딩 유사도 — 현재는 `difflib` 기반(변형 웜 탐지율은 평가 필요).
- YARA·Defender·VirusTotal 스크립트 검사 — 현재는 정규식 패턴 규칙.

자세한 기능 경계는 [`기능명세서.md`](기능명세서.md) 참고.
